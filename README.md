# Visualizer

Welcome to the **A* Maze Visualizer**! 🧩  

This project lets you **watch the A* algorithm in action**, navigating from the start to the goal step by step.  

## Features

- Random maze generation (press `M`)
- Step-by-step animation of A* pathfinding
- Color-coded cells:
  - **Visited cells** – gray
  - **Found path** – green
- Start and goal highlighted (red and cyan)

## How to Run

1. Clone the repository:
```bash
git clone https://github.com/dzaykk/visualizer.git
cd visualizer
```

2. Open the project in Visual Studio (MSVC) or use CMake:
```bash
mkdir build
cd build
cmake ..
cmake --build .
```

3. Run the executable and enjoy the visualization!
